# 123140178_EksplorasiMandiri_Mahadata

Eksplorasi Mandiri Mahadata: Apache Spark untuk Prediksi Smart Grid
Repositori ini berisi kode eksperimen replikasi parsial dari artikel jurnal "Big data resolving using Apache Spark for load forecasting and demand response in smart grid: A case study of Low Carbon London Project" (Ali et al., 2024).

Lingkungan Eksekusi:
- Platform: Google Colab
- Versi Python: 3.13.15
- Versi PySpark: 4.0.4

Langkah Reprodusibilitas (Cara Menjalankan):
1. Buka file notebook .ipynb ini menggunakan Google Colab.
2. Jalankan sel kode secara berurutan dari atas ke bawah.
3. Dataset tidak dilampirkan langsung karena ukurannya yang besar (>1 GB), namun skrip sudah dilengkapi kode kagglehub untuk mengunduh dataset secara otomatis dari Kaggle (jeanmidev/smart-meters-in-london).
